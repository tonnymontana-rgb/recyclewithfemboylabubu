# recyclewithfemboylabubu
Tekstil endüstrisinde oluşan polyester atıklarını geri kazanmak

Döngüsel ekonomiye katkı sağlamak

3D baskı teknolojisinde sürdürülebilir ve çevre dostu hammaddeler geliştirmek

⚙️ Süreç

Atık toplama: Kullanılmayan / hurda polyester kumaşların toplanması

Ayrıştırma ve temizleme: Kumaşların geri dönüşüme uygun hale getirilmesi

Granül hale getirme: Polyesterin küçük parçacıklara dönüştürülmesi

Filament üretimi: Granüllerin eritilip standart çaplarda 3D baskı filamentine dönüştürülmesi

Test ve uygulama: Üretilen filamentlerin 3D yazıcılarda dayanıklılık, esneklik ve baskı kalitesi açısından test edilmesi

🌍 Katkı

Tekstil atıklarının çöp olmaktan çıkıp yüksek katma değerli ürünlere dönüşmesi

3D yazıcı kullanıcıları için ekonomik, çevre dostu filament alternatifi oluşturulması

Sürdürülebilirlik ve inovasyonun bir araya getirilmesi
